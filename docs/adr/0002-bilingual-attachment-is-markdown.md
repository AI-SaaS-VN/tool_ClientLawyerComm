# A published attachment opens as an HTML translation page

Attachment translations can be long, so they are not pasted beside the file name. On 2026-10-08 the user first chose an extra downloadable Markdown file: extracted source text, then one translation (Chinese to Vietnamese, or Vietnamese to Traditional Chinese). On 2026-10-09 the user replaced that download with a separate HTML page opened by “打开附件翻译”, because HTML is easier for the client and the lawyer to read than Markdown. The page shows the same source text, then the same one translation. Page wording follows the viewer's screen language. The original file stays as uploaded and stays downloadable. The later paragraph-numbered bilingual DOCX remains a separate, later document. Selectable PDF and DOCX text is extracted on the machine; photos and scanned pages are read by Kimi. If extraction fails, the page is not created.
